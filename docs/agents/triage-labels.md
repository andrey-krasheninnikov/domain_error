# Triage labels

Use this mapping whenever a skill names a canonical triage role.

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Awaiting maintainer evaluation |
| `needs-info` | `needs-info` | Awaiting information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for implementation |
| `ready-for-human` | `ready-for-human` | Requires maintainer judgment or manual work |
| `wontfix` | `wontfix` | Will not be implemented |

Category labels such as `bug` and `enhancement` are separate from these
state roles. This file records the mapping; it does not create labels.
